# Device photos

Photos shown on the fleet cards and on the "physical device" panel of the detail page.

Name a file after the node and reference it from `image` in `public/servers.json`, e.g. `"image": "/images/web01.jpg"`.
Operators can also replace a photo from the dashboard itself; that override is kept in the display's localStorage.

Aim for a 4:3 or 16:9 photo, 800–1200 px on the long side and under 300 KB.
